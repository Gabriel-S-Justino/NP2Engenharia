# Etapas manuais da equipe

A entrega não baixa documentos reais. O responsável adiciona arquivos pela Biblioteca usando o token administrativo e acompanha a indexação existente.

Para usar o chat, crie uma conta em Sua conta. Não é necessário conhecer o ADMIN_TOKEN para perguntar. Esse token continua necessário para alterar o acervo e vincular histórico anônimo anterior. Na mesma conta, conversas novas aparecem no servidor e em outros dispositivos.

A matriz real já contém casos conferidos no PDF existente, com hash, edição e páginas físicas. Trocar ou atualizar o acervo exige revisar a matriz e a calibração antes de executar uma avaliação. Não marque um conjunto como pronto sem conferir as fontes.

Configure SMTP e domínio de autenticação próprios, teste o recebimento do código de recuperação e homologue dispositivos antes de ampliar o uso. O material atual é antigo e não deve ser apresentado como legislação vigente.

Credenciais são configuradas no servidor, nunca no repositório. Veja [Produção](PRODUCAO.md) e [Contas](CONTAS_E_CONVERSAS.md).
